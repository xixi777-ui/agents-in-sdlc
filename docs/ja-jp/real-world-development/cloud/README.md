**[GitHub Copilot cloud agent](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** を使うと、GitHub Copilot をクラウドで非同期に動作させられます。GitHub で作業を割り当てると、cloud agent がバックグラウンドでリポジトリを調べ、変更を行い、プルリクエストを開きます。その間、ほかの作業を続けられます。

これらの演習では、まず cloud agent が従うカスタム命令を追加し、その後 GitHub issue を割り当てて実装を任せます。カスタムエージェントを確認して使い、エージェントの進め方を調整し、エージェント ダッシュボードからセッションの進捗を監視して案内し、最後にプルリクエストをレビューして結果を反復的に改善します。

## 前提条件

このワークショップに参加する前に、次の準備ができていることを確認してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランを利用できる GitHub アカウント
- [ ] アカウントまたは組織で Copilot cloud agent が有効になっている

> [!TIP]
> 有料プランを利用していない場合、認証済みの学生は [GitHub Education][callout-student-plan-education] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使用するエージェント、MCP、コードレビュー、Copilot CLI の機能が含まれているため、すべての環境の演習を完了できます。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> Cloud agent は **Copilot Student、Pro、Pro+、Business、Enterprise** で利用できます。Copilot Free を除くすべてのプランが対象です。Copilot Business または Enterprise では、管理者が組織で有効にする必要があります。

> [!NOTE]
> この環境では MCP を扱いません。Copilot で MCP サーバーを使う方法については、[CLI 環境](../cli/)または [VS Code 環境](../vscode/)を参照してください。
